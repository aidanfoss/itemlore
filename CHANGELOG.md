# Changelog

- 5.4.4: Updated Minecraft 26.3 compatibility with Fabric Loader 0.20.1 and Fabric API 0.165.2.
- Added support for **SgtVeinminer**: Blocks mined via vein mining now correctly count towards item statistics.
- Added support for **Tree-Harvester**: Blocks mined via treeharvester correctly count towards item statistics.
- Fixed a bug where the *UNSTACKABLE* setting was still allowing application to stackable items via ForceLore.
